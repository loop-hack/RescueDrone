# RescueAI

An edge-AI disaster search and rescue drone project.

## Phase 1: AI Prototype

Initial objectives:
- Detect people in images and recorded video.
- Save detection evidence.
- Benchmark inference latency and throughput.
- Evaluate detection quality on rescue scenarios.

## Development Environment

- Python 3.11
- OpenCV
- PyTorch
- Ultralytics

## Status

Phase 1 — Initial computer vision prototype.
